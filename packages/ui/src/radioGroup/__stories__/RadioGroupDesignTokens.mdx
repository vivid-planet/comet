# RadioGroup design tokens

A theme styles the radio group through these [design tokens](?path=/docs/foundations-design-tokens--docs). All of them are shared with other components, so changing one changes those components too. They style both the group, with its label, description and error message, and each `Radio` option in it.

[Theme overview](?path=/docs/foundations-theme-overview--docs) shows each token's value in every theme.

| Token                                                                                                                                                                                               | In the radio group                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                                         | Background of the circle, also of the selected option.                                                                                                                                             |
| `--dextinity-color-border-strong`                                                                                                                                                                   | Border color of the circle of an unselected option.                                                                                                                                                |
| `--dextinity-color-border-hover`                                                                                                                                                                    | Border color of the circle of an unselected option while its circle or label is hovered. A `readOnly` or invalid option keeps its border.                                                          |
| `--dextinity-color-primary`                                                                                                                                                                         | Border color of the selected option's circle, and color of the dot. In an invalid group the circle keeps its danger border, but the dot stays primary.                                             |
| `--dextinity-color-primary-hover`                                                                                                                                                                   | Border color of the circle and color of the dot of the selected option while its circle or label is hovered. A `readOnly` or invalid option keeps its colors.                                      |
| `--dextinity-color-danger`                                                                                                                                                                          | Border color of every circle in an invalid group, also of the selected option and while hovered. Color of the asterisk after the label of a `required` group, and text color of the error message. |
| `--dextinity-control-toggle-size`                                                                                                                                                                   | Width and height of the circle. The dot is half as large.                                                                                                                                          |
| `--dextinity-control-border-width`                                                                                                                                                                  | Border width of the circle.                                                                                                                                                                        |
| `--dextinity-radius-full`                                                                                                                                                                           | Corner radius of the circle and the dot.                                                                                                                                                           |
| `--dextinity-color-foreground`                                                                                                                                                                      | Text color of the group's label and of each option's label.                                                                                                                                        |
| `--dextinity-font-family-body`                                                                                                                                                                      | Font family of the group's label, the options' labels, the description and the error message.                                                                                                      |
| `--dextinity-typography-label-font-size`, `--dextinity-typography-label-line-height`, `--dextinity-typography-label-font-weight`, `--dextinity-typography-label-letter-spacing`                     | Size, line height, weight and letter spacing of the group's label.                                                                                                                                 |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing`                         | Size, line height, weight and letter spacing of each option's label. The circle is centered on the label's first line.                                                                             |
| `--dextinity-typography-body-small-font-size`, `--dextinity-typography-body-small-line-height`, `--dextinity-typography-body-small-font-weight`, `--dextinity-typography-body-small-letter-spacing` | Size, line height, weight and letter spacing of the description and the error message.                                                                                                             |
| `--dextinity-color-foreground-muted`                                                                                                                                                                | Text color of the description.                                                                                                                                                                     |
| `--dextinity-space-xs`                                                                                                                                                                              | Gap between the group's label, the options, the description and the error message, and between the label and its asterisk.                                                                         |
| `--dextinity-space-sm`                                                                                                                                                                              | Gap between the stacked options of a vertical group, and between the lines of a `horizontal` group whose options wrap.                                                                             |
| `--dextinity-space-lg`                                                                                                                                                                              | Gap between the options side by side in a `horizontal` group.                                                                                                                                      |
| `--dextinity-space-md`                                                                                                                                                                              | Gap between an option's circle and its label.                                                                                                                                                      |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                                                     | Outline of the circle focused with the keyboard.                                                                                                                                                   |
| `--dextinity-opacity-disabled`                                                                                                                                                                      | Opacity of a disabled option, its circle and label together. A `disabled` group dims all its options, but not its label, description or error message.                                             |
| `--dextinity-motion-duration-short`, `--dextinity-motion-easing`                                                                                                                                    | Transition of the circle's border color and the dot's color, and of the dot as it grows in when the option is selected and shrinks away when it is deselected.                                     |
