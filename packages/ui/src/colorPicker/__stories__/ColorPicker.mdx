## Slots

`className` and `style` go to the field's outer element, the `dextinityColorPicker` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`, `required`, `readonly`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

A color picker is a [`FormField`](?path=/docs/components-formfield--docs) around its input and presets, so its root carries both root classes, `dextinityFormField dextinityColorPicker`, and the label, description and error have the form field's classes. `ref` and the props the component doesn't handle go to the hex input.

| Slot                | Element                             | Class                                   | What it is                                                                                                                                                                                                                                             |
| ------------------- | ----------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `group`             | `<div>`                             | `dextinityColorPicker__group`           | The box with the border around the swatch, the hex input and the clear button.                                                                                                                                                                         |
| `swatch`            | `<span>`                            | `dextinityColorPicker__swatch`          | The square at the input's start that shows the color. It has `data-empty` and shows a diagonal line while there is no color.                                                                                                                           |
| `picker`            | `<input type="color">`              | `dextinityColorPicker__picker`          | The invisible color input that covers the swatch and opens the browser's color picker. Tab and assistive technology skip it unless `pickerLabel` names it. Not rendered in a `readOnly` field.                                                         |
| `input`             | `<input>` (Base UI `Input`)         | `dextinityColorPicker__input`           | The hex input, which receives focus and the props the component doesn't handle.                                                                                                                                                                        |
| `clear`             | `<button>`                          | `dextinityColorPicker__clear`           | The button that empties the field. Shown only with `clearLabel`, while the input isn't empty and the field is neither `required`, `readOnly` nor disabled, also by an enclosing Base UI `Fieldset`. Its `children`, the `close` icon, can be replaced. |
| `presets`           | `<div>` with the `group` role       | `dextinityColorPicker__presets`         | The element around the preset buttons, which the label names for assistive technology. Rendered only with `presets`, in a field that isn't `readOnly`.                                                                                                 |
| `preset`            | `<button>`                          | `dextinityColorPicker__preset`          | The button of each preset. It has `aria-pressed="true"` and `data-pressed` while its color is the value.                                                                                                                                               |
| `label`             | `<label>` (Base UI `Field.Label`)   | `dextinityFormField__label`             | The label, which holds `label` and the required indicator.                                                                                                                                                                                             |
| `requiredIndicator` | `<span>`                            | `dextinityFormField__requiredIndicator` | The asterisk after the label of a `required` field. Assistive technology skips it.                                                                                                                                                                     |
| `description`       | `<p>` (Base UI `Field.Description`) | `dextinityFormField__description`       | The `description`.                                                                                                                                                                                                                                     |
| `error`             | `<div>` (Base UI `Field.Error`)     | `dextinityFormField__error`             | The error message. Rendered only while there is an error to show.                                                                                                                                                                                      |

## Design tokens

A theme styles the color picker's input, swatch, clear button and presets through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the color picker's own: they're shared tokens, which other components can use too. The box around the input looks like a `TextField`'s input, so a form looks uniform. `ColorPicker` renders a `FormField` for its label, description and error message, so the [FormField design tokens](?path=/docs/components-formfield--docs#design-tokens) style those and the space between the parts. The clear button shows the `close` icon of the [icon set](?path=/docs/foundations-icons--docs), which a theme can replace. In forced-colors mode, such as a Windows contrast theme, the swatch and each preset keep their color and get a border in the system's text color, twice as wide and in the system's selected-item color for the selected preset. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the color picker                                                                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                 | Background of the box around the swatch, the input and the clear button, and of the swatch while there is no color. Color of the gap inside the ring of the selected preset.                                                     |
| `--dextinity-color-border-strong`                                                                                                                                           | Border color of the box, and of the swatch and each preset, so a color close to the background stays visible. Color of the diagonal line in the swatch while there is no color.                                                  |
| `--dextinity-color-border-hover`                                                                                                                                            | Border color of the hovered box, and of a hovered preset that isn't selected. A focused, invalid or `readOnly` box keeps its border.                                                                                             |
| `--dextinity-color-primary`                                                                                                                                                 | Border color of the box while the input has focus, also when it was focused by clicking. An invalid field keeps its danger border.                                                                                               |
| `--dextinity-color-danger`                                                                                                                                                  | Border color of an invalid field, also while focused or hovered. The field is invalid while it shows an error: the `error` prop, or the browser's message for a failed check, such as `required` or text that isn't a hex color. |
| `--dextinity-control-border-width`                                                                                                                                          | Border width of the box, the swatch and each preset, and width of the diagonal line in an empty swatch. The ring of the selected preset is twice as wide, with a gap as wide again.                                              |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of the box.                                                                                                                                                                                                        |
| `--dextinity-radius-small`                                                                                                                                                  | Corner radius of the swatch, the clear button and each preset.                                                                                                                                                                   |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of the box. The color picker comes in this one size. The swatch, the clear button and each preset are squares as high as the box, minus `--dextinity-space-sm` above and below.                                   |
| `--dextinity-space-sm`                                                                                                                                                      | Space between the swatch or the clear button and the box's edges, and gap between the presets.                                                                                                                                   |
| `--dextinity-space-md`                                                                                                                                                      | Horizontal padding around the hex value, between the swatch and the clear button.                                                                                                                                                |
| `--dextinity-space-xs`                                                                                                                                                      | Extra space above the presets, in addition to the form field's gap below the box.                                                                                                                                                |
| `--dextinity-color-surface-hover`                                                                                                                                           | Background of the hovered clear button.                                                                                                                                                                                          |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the hex value and color of the clear button's icon. Color of the ring of the selected preset.                                                                                                                      |
| `--dextinity-color-foreground-muted`                                                                                                                                        | Text color of the `placeholder`.                                                                                                                                                                                                 |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the hex value and the placeholder.                                                                                                                                                                                |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Size, line height, weight and letter spacing of the hex value and the placeholder. Digits have equal widths. The clear button's icon is 1.25 times the font size.                                                                |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline around the box while the input has focus, also when it was focused by clicking. Outline of the swatch with a `pickerLabel`, of a preset and, inside its edges, of the clear button, when focused with the keyboard.      |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of the box and of each preset of a `disabled` field, also of one that an enclosing Base UI `Fieldset` disables.                                                                                                          |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the box's border color as it is hovered, focused or marked invalid, and of the clear button's background on hover. The easing also applies to the presets' transition.                                             |
| `--dextinity-motion-duration-short`                                                                                                                                         | Transition of a preset's border and ring as it is hovered or selected.                                                                                                                                                           |
