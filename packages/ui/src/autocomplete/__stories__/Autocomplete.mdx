## Slots

`className` and `style` go to the field's outer element, the `dextinityAutocomplete` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`, `required`, `readonly`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

An autocomplete is a [`FormField`](?path=/docs/components-formfield--docs) around the input, so its root carries both root classes, `dextinityFormField dextinityAutocomplete`, and the label, description and error have the form field's classes. The parts of the list, from `positioner` to `empty`, render only while the list is open, at the end of `<body>`: style them through their classes, not as descendants of the field. Without `emptyMessage`, the positioner is `hidden` while no option matches. The positioner carries the theme and color scheme of a [`ThemeSwitch`](?path=/docs/components-themeswitch--docs) around the autocomplete, so the list looks like the input.

| Slot                | Element                                     | Class                                    | What it is                                                                                                                             |
| ------------------- | ------------------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `input`             | `<input>` (Base UI `Combobox.Input`)        | `dextinityAutocomplete__input`           | The input, which has the `combobox` role and gets the props the component doesn't handle.                                              |
| `control`           | `<div>` (Base UI `Combobox.InputGroup`)     | `dextinityAutocomplete__control`         | The bordered box around the input and its buttons, which looks like a text field's input.                                              |
| `clear`             | `<button>` (Base UI `Combobox.Clear`)       | `dextinityAutocomplete__clear`           | The button that clears the value. Rendered only with `clearLabel`, while an option is selected.                                        |
| `trigger`           | `<button>` (Base UI `Combobox.Trigger`)     | `dextinityAutocomplete__trigger`         | The chevron button at the end of the box, which opens and closes the list. Tab skips it: the input opens the list with the arrow keys. |
| `positioner`        | `<div>` (Base UI `Combobox.Positioner`)     | `dextinityAutocomplete__positioner`      | Positions the list against the box. Its props, such as `side`, `align` and `sideOffset`, change where the list opens.                  |
| `popup`             | `<div>` (Base UI `Combobox.Popup`)          | `dextinityAutocomplete__popup`           | The surface of the list, which floats above the page.                                                                                  |
| `list`              | `<div>` (Base UI `Combobox.List`)           | `dextinityAutocomplete__list`            | The element around the options, which has the `listbox` role and scrolls when the options don't fit.                                   |
| `option`            | `<div>` (Base UI `Combobox.Item`)           | `dextinityAutocomplete__option`          | Each option, which has the `option` role.                                                                                              |
| `optionText`        | `<span>`                                    | `dextinityAutocomplete__optionText`      | The option's label.                                                                                                                    |
| `optionIndicator`   | `<span>` (Base UI `Combobox.ItemIndicator`) | `dextinityAutocomplete__optionIndicator` | The check mark after the selected option's label. Rendered only for the selected option.                                               |
| `empty`             | `<div>` (Base UI `Combobox.Empty`)          | `dextinityAutocomplete__empty`           | The element that holds `emptyMessage`. It stays in the open list, so screen readers announce the message when no option matches.       |
| `label`             | `<label>` (Base UI `Field.Label`)           | `dextinityFormField__label`              | The label, which holds `label` and the required indicator.                                                                             |
| `requiredIndicator` | `<span>`                                    | `dextinityFormField__requiredIndicator`  | The asterisk after the label of a `required` autocomplete. Assistive technology skips it.                                              |
| `description`       | `<p>` (Base UI `Field.Description`)         | `dextinityFormField__description`        | The `description`.                                                                                                                     |
| `error`             | `<div>` (Base UI `Field.Error`)             | `dextinityFormField__error`              | The error message. Rendered only while there is an error to show.                                                                      |

The icons in the clear and the chevron button have the class `dextinityAutocomplete__buttonIcon` besides the icon's own, `dextinityIcon`. A theme replaces them and the check mark of the selected option through their icon tokens, `--dextinity-icon-close`, `--dextinity-icon-chevron-down` and `--dextinity-icon-check`: see [Icons](?path=/docs/foundations-icons--docs).

## Design tokens

A theme styles the autocomplete's input and its list of options through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the autocomplete's own: they're shared tokens, which other components can use too. The box around the input uses the same tokens as a text field's input, and the list the same as a select's, so they look alike in a form. `Autocomplete` renders a `FormField` for its label, description and error message, so the [FormField design tokens](?path=/docs/components-formfield--docs#design-tokens) style those and the space between the parts. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the autocomplete                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                 | Background of the box around the input, and of the list.                                                                                                                                                                                                                                 |
| `--dextinity-color-border-strong`                                                                                                                                           | Border color of the box.                                                                                                                                                                                                                                                                 |
| `--dextinity-color-border-hover`                                                                                                                                            | Border color of the hovered box. A focused, open, invalid or `readOnly` box keeps its border.                                                                                                                                                                                            |
| `--dextinity-color-primary`                                                                                                                                                 | Border color of the box while the input has focus, also when it was focused by clicking, and while the list is open. An invalid box keeps its danger border.                                                                                                                             |
| `--dextinity-color-danger`                                                                                                                                                  | Border color of an invalid box, also while focused, open or hovered. The box is invalid while the field shows an error: the `error` prop, or the browser's message for a failed check such as `required`.                                                                                |
| `--dextinity-control-border-width`                                                                                                                                          | Border width of the box.                                                                                                                                                                                                                                                                 |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of the box and of the list.                                                                                                                                                                                                                                                |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of the box. The autocomplete comes in this one size.                                                                                                                                                                                                                      |
| `--dextinity-space-lg`                                                                                                                                                      | Padding at the start of the box, and horizontal padding of each option and of the empty message, so they line up with the text in the input. At the end of the box, it is reduced by the buttons' own space, so the chevron sits where a select's does.                                  |
| `--dextinity-space-xs`                                                                                                                                                      | Gap between the input, the clear button and the chevron button. Space above the first and below the last option.                                                                                                                                                                         |
| `--dextinity-space-sm`                                                                                                                                                      | Gap between an option's label and its check mark, and vertical padding of each option and of the empty message.                                                                                                                                                                          |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the input, of the options and of the check mark, and color of a hovered button's icon.                                                                                                                                                                                     |
| `--dextinity-color-foreground-muted`                                                                                                                                        | Text color of the `placeholder` and of the empty message, and color of the buttons' icons.                                                                                                                                                                                               |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the input, the options and the empty message.                                                                                                                                                                                                                             |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Size, line height, weight and letter spacing of the input, the placeholder, the options and the empty message. The buttons are twice as large as the text, their icons and the check mark 1.25 times.                                                                                    |
| `--dextinity-color-surface-hover`                                                                                                                                           | Background of a hovered button in the box, and of the highlighted option: hovered, or reached with the arrow keys.                                                                                                                                                                       |
| `--dextinity-radius-small`                                                                                                                                                  | Corner radius of the hover background of the buttons in the box.                                                                                                                                                                                                                         |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline of the box while the input has focus. Like a text field's input, it shows also when the input was focused by clicking. The highlighted option has a transparent outline of the same width inside its edge, which forced-colors mode shows in place of the background it removes. |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of the box of a `disabled` field, and of a disabled option.                                                                                                                                                                                                                      |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the box's border color as it is hovered, focused or marked invalid, of the buttons' hover colors, of the clear button as it fades in and out, and of the chevron as it turns over while the list is open.                                                                  |
| `--dextinity-color-border`                                                                                                                                                  | Border color of the list.                                                                                                                                                                                                                                                                |
| `--dextinity-shadow-popup`                                                                                                                                                  | Shadow of the list, which floats above the page.                                                                                                                                                                                                                                         |
| `--dextinity-motion-duration-short`                                                                                                                                         | Transition of the list as it fades and grows in when it opens, and out when it closes, with the box's easing.                                                                                                                                                                            |
| `--dextinity-z-index-popup`                                                                                                                                                 | Stacking order of the list, which renders at the end of the page, above the page and above dialogs.                                                                                                                                                                                      |
