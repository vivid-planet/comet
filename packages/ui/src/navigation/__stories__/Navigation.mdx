## Slots

The three components take `className` and `style` for their outer element: the `<nav>` of `Navigation`, `dextinityNavigation`, and the list items of `NavigationGroup` and `NavigationItem`, `dextinityNavigationGroup` and `dextinityNavigationItem`. `slotProps` adjusts their inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state that returns them: `level` for a group, `active` and `level` for an item; the navigation's owner state is empty. `render` replaces a slot's element; `NavigationItem`'s own `render` prop replaces its link, for a router's link component. See [Customization](?path=/docs/foundations-customization--docs).

| Slot        | Component         | Element                                    | Class                                 | What it is                                                                                                                          |
| ----------- | ----------------- | ------------------------------------------ | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `list`      | `Navigation`      | `<ul>`                                     | `dextinityNavigation__list`           | The list of the entries, `children`.                                                                                                |
| `trigger`   | `NavigationGroup` | `<button>` (Base UI `Collapsible.Trigger`) | `dextinityNavigationGroup__trigger`   | The button that opens and closes the group. It holds the icon, `label` and the indicator.                                           |
| `icon`      | `NavigationGroup` | `<span>`                                   | `dextinityNavigationGroup__icon`      | The `icon`. Rendered only when the group has one. Assistive technology skips it.                                                    |
| `indicator` | `NavigationGroup` | `<span>`                                   | `dextinityNavigationGroup__indicator` | The chevron at the end of the button, which turns over while the group is open. Assistive technology skips it.                      |
| `panel`     | `NavigationGroup` | `<ul>` (Base UI `Collapsible.Panel`)       | `dextinityNavigationGroup__panel`     | The nested list of the group's entries, `children`. It stays in the document while the group is closed, so find in page finds them. |
| `link`      | `NavigationItem`  | `<a>`                                      | `dextinityNavigationItem__link`       | The link, which holds the icon and `children` and gets the props the component doesn't handle.                                      |
| `icon`      | `NavigationItem`  | `<span>`                                   | `dextinityNavigationItem__icon`       | The `icon`. Rendered only when the item has one. Assistive technology skips it.                                                     |

## Design tokens

A theme styles the navigation through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the navigation's own: they're shared tokens, which other components can use too. They style the items, `NavigationItem`, and the buttons that open and close a `NavigationGroup` alike, so that both line up. A group's chevron is the `chevron-down` icon of the [icon set](?path=/docs/foundations-icons--docs), which a theme can replace. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the navigation                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--dextinity-color-foreground`                                                                                                                                              | Text and icon color of the items and of the groups' buttons, including the chevron.                                                                                                                                                                                                              |
| `--dextinity-color-surface-hover`                                                                                                                                           | Background of a hovered item or group button. The `active` item keeps its own background.                                                                                                                                                                                                        |
| `--dextinity-color-primary-subtle`                                                                                                                                          | Background of the `active` item. In forced colors mode, the system's colors of a selected item mark it instead.                                                                                                                                                                                  |
| `--dextinity-color-primary`                                                                                                                                                 | Text and icon color of the `active` item.                                                                                                                                                                                                                                                        |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the items and the groups' labels.                                                                                                                                                                                                                                                 |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Text style of the items and the groups' labels. Icons and the chevron are 1.25 times as large as the text. A text that wraps makes its row taller.                                                                                                                                               |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of each row: an item or a group's button.                                                                                                                                                                                                                                         |
| `--dextinity-space-lg`                                                                                                                                                      | Horizontal padding of each row.                                                                                                                                                                                                                                                                  |
| `--dextinity-space-xs`                                                                                                                                                      | Vertical padding of each row, which keeps wrapped text off its edges.                                                                                                                                                                                                                            |
| `--dextinity-space-sm`                                                                                                                                                      | Gap between an icon and the text, and the least gap between a group's label and its chevron. Together with the icon size, it is also the indentation of each nested level: the items of a group with an icon line up with its label, those of a group without one are indented one step further. |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of a row's background and of its focus outline.                                                                                                                                                                                                                                    |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`                                                                                                              | Outline of an item or a group's button focused with the keyboard. It is drawn inside the row, so that a scrolling sidebar doesn't clip it.                                                                                                                                                       |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of a row's background on hover, of a group's height as it opens and closes, and of its chevron as it turns over.                                                                                                                                                                      |
