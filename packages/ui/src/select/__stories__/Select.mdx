## Slots

`className` and `style` go to the field's outer element, the `dextinitySelect` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`, `required`, `readonly`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

A select is a [`FormField`](?path=/docs/components-formfield--docs) around the trigger, so its root carries both root classes, `dextinityFormField dextinitySelect`, and the label, description and error have the form field's classes. The parts of the list, from `positioner` to `optionIndicator`, render only while the list is open, at the end of `<body>`: style them through their classes, not as descendants of the field. The positioner carries the theme and color scheme of a [`ThemeSwitch`](?path=/docs/foundations-themeswitch--docs) around the select, so the list looks like the trigger.

| Slot                | Element                                   | Class                                   | What it is                                                                                                                                    |
| ------------------- | ----------------------------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `trigger`           | `<button>` (Base UI `Select.Trigger`)     | `dextinitySelect__trigger`              | The button that shows the selected option and opens the list. It has the `combobox` role and gets the props the component doesn't handle.     |
| `value`             | `<span>` (Base UI `Select.Value`)         | `dextinitySelect__value`                | The text in the trigger: the selected option's label, or the `placeholder` while nothing is selected.                                         |
| `icon`              | `<span>` (Base UI `Select.Icon`)          | `dextinitySelect__icon`                 | The element around the chevron at the end of the trigger. Assistive technology skips it.                                                      |
| `positioner`        | `<div>` (Base UI `Select.Positioner`)     | `dextinitySelect__positioner`           | Positions the list against the trigger. Its props, such as `side`, `align` and `sideOffset`, change where the list opens.                     |
| `popup`             | `<div>` (Base UI `Select.Popup`)          | `dextinitySelect__popup`                | The surface of the list, which floats above the page.                                                                                         |
| `list`              | `<div>` (Base UI `Select.List`)           | `dextinitySelect__list`                 | The element around the options, which has the `listbox` role and scrolls when the options don't fit.                                          |
| `option`            | `<div>` (Base UI `Select.Item`)           | `dextinitySelect__option`               | Each option, which has the `option` role.                                                                                                     |
| `optionText`        | `<div>` (Base UI `Select.ItemText`)       | `dextinitySelect__optionText`           | The option's label.                                                                                                                           |
| `optionIndicator`   | `<span>` (Base UI `Select.ItemIndicator`) | `dextinitySelect__optionIndicator`      | The check mark after the selected option's label. Rendered only for the selected option.                                                      |
| `label`             | `<div>` (Base UI `Field.Label`)           | `dextinityFormField__label`             | The label, which holds `label` and the required indicator. It isn't a `<label>`, so clicking it focuses the trigger without opening the list. |
| `requiredIndicator` | `<span>`                                  | `dextinityFormField__requiredIndicator` | The asterisk after the label of a `required` select. Assistive technology skips it.                                                           |
| `description`       | `<p>` (Base UI `Field.Description`)       | `dextinityFormField__description`       | The `description`.                                                                                                                            |
| `error`             | `<div>` (Base UI `Field.Error`)           | `dextinityFormField__error`             | The error message. Rendered only while there is an error to show.                                                                             |

## Design tokens

A theme styles the select's trigger and its list of options through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the select's own: they're shared tokens, which other components can use too. The trigger uses the same tokens as a text field's input, so both look alike in a form. `Select` renders a `FormField` for its label, description and error message, so the [FormField design tokens](?path=/docs/components-formfield--docs#design-tokens) style those and the space between the parts. The trigger shows the `chevron-down` icon and the selected option the `check` icon of the [icon set](?path=/docs/foundations-icons--docs), which a theme can replace. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the select                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                 | Background of the trigger and of the list.                                                                                                                                                                        |
| `--dextinity-color-border-strong`                                                                                                                                           | Border color of the trigger.                                                                                                                                                                                      |
| `--dextinity-color-border-hover`                                                                                                                                            | Border color of the hovered trigger. A focused, open, invalid or `readOnly` trigger keeps its border.                                                                                                             |
| `--dextinity-color-primary`                                                                                                                                                 | Border color of the focused trigger, also when it was focused by clicking, and of the trigger while the list is open. An invalid trigger keeps its danger border.                                                 |
| `--dextinity-color-danger`                                                                                                                                                  | Border color of an invalid trigger, also while focused, open or hovered. The trigger is invalid while the field shows an error: the `error` prop, or the browser's message for a failed check such as `required`. |
| `--dextinity-control-border-width`                                                                                                                                          | Border width of the trigger.                                                                                                                                                                                      |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of the trigger and of the list.                                                                                                                                                                     |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of the trigger. The select comes in this one size.                                                                                                                                                 |
| `--dextinity-space-lg`                                                                                                                                                      | Horizontal padding inside the trigger and inside each option, so the options' labels line up with the selected one in the trigger.                                                                                |
| `--dextinity-space-sm`                                                                                                                                                      | Gap between the value and the chevron, and between an option's label and its check mark. Vertical padding of each option.                                                                                         |
| `--dextinity-space-xs`                                                                                                                                                      | Space above the first and below the last option.                                                                                                                                                                  |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the selected value, of the options and of the check mark.                                                                                                                                           |
| `--dextinity-color-foreground-muted`                                                                                                                                        | Text color of the `placeholder`, and color of the chevron.                                                                                                                                                        |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the trigger and of the options.                                                                                                                                                                    |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Size, line height, weight and letter spacing of the value, the placeholder and the options. The chevron and the check mark are 1.25 times as large as the text.                                                   |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline of the trigger focused with the keyboard. The highlighted option has a transparent outline of the same width inside its edge, which forced-colors mode shows in place of the background it removes.       |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of the trigger of a `disabled` field, and of a disabled option.                                                                                                                                           |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the trigger's border color as it is hovered, focused or marked invalid, and of the chevron as it turns over while the list is open.                                                                 |
| `--dextinity-color-border`                                                                                                                                                  | Border color of the list.                                                                                                                                                                                         |
| `--dextinity-shadow-popup`                                                                                                                                                  | Shadow of the list, which floats above the page.                                                                                                                                                                  |
| `--dextinity-color-surface-hover`                                                                                                                                           | Background of the highlighted option: hovered, or reached with the arrow keys.                                                                                                                                    |
| `--dextinity-motion-duration-short`                                                                                                                                         | Transition of the list as it fades and grows in when it opens, and out when it closes, with the trigger's easing.                                                                                                 |
| `--dextinity-z-index-popup`                                                                                                                                                 | Stacking order of the list, which renders at the end of the page, above the page and above dialogs.                                                                                                               |
