## Slots

`className` and `style` go to the field's outer element, the `dextinityFormField` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`orientation`, `disabled`, `required`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

| Slot                | Element                             | Class                                   | What it is                                                                                                                               |
| ------------------- | ----------------------------------- | --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `label`             | `<label>` (Base UI `Field.Label`)   | `dextinityFormField__label`             | The label, which holds `label` and the required indicator.                                                                               |
| `requiredIndicator` | `<span>`                            | `dextinityFormField__requiredIndicator` | The asterisk after the label of a `required` field. Assistive technology skips it.                                                       |
| `content`           | `<div>`                             | `dextinityFormField__content`           | The element around the control, the description, the warning and the error. It has `display: contents` unless the field is `horizontal`. |
| `description`       | `<p>` (Base UI `Field.Description`) | `dextinityFormField__description`       | The `description`.                                                                                                                       |
| `warning`           | `<p>` (Base UI `Field.Description`) | `dextinityFormField__warning`           | The `warning`. Rendered only while there is a warning and no error.                                                                      |
| `error`             | `<div>` (Base UI `Field.Error`)     | `dextinityFormField__error`             | The error message. Rendered only while there is an error to show.                                                                        |

## Design tokens

A theme styles the form field through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the form field's own: they're shared tokens, which other components can use too. `TextField` renders a `FormField`, so they style a text field's label, description and error message, and the gaps between its parts, as well. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                                               | In the form field                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-foreground`                                                                                                                                                                      | Text color of the label.                                                                                                                                                        |
| `--dextinity-typography-label-font-size`, `--dextinity-typography-label-line-height`, `--dextinity-typography-label-font-weight`, `--dextinity-typography-label-letter-spacing`                     | Size, line height, weight and letter spacing of the label.                                                                                                                      |
| `--dextinity-color-danger`                                                                                                                                                                          | Color of the asterisk after the label of a `required` field, and text color of the error message.                                                                               |
| `--dextinity-color-foreground-muted`                                                                                                                                                                | Text color of the description.                                                                                                                                                  |
| `--dextinity-color-warning`                                                                                                                                                                         | Text color of the warning.                                                                                                                                                      |
| `--dextinity-space-lg`                                                                                                                                                                              | Gap between the label column and the control column of a `horizontal` field.                                                                                                    |
| `--dextinity-control-height-medium`                                                                                                                                                                 | Moves the label of a `horizontal` field down, so its first line is centered on a control of this height.                                                                        |
| `--dextinity-typography-body-small-font-size`, `--dextinity-typography-body-small-line-height`, `--dextinity-typography-body-small-font-weight`, `--dextinity-typography-body-small-letter-spacing` | Size, line height, weight and letter spacing of the description, the warning and the error message.                                                                             |
| `--dextinity-font-family-body`                                                                                                                                                                      | Font family of the label, the description and the error message.                                                                                                                |
| `--dextinity-space-xs`                                                                                                                                                                              | Gap between the label, the control, the description and the error message, and between the label and its asterisk.                                                              |
| `--dextinity-opacity-disabled`                                                                                                                                                                      | Opacity of the label of a `disabled` field, asterisk included. The description and the error message stay fully readable, so the description can say why the field is disabled. |
