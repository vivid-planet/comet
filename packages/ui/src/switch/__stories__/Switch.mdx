## Slots

`className` and `style` go to the switch's outer element, the `dextinitySwitch` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

| Slot      | Element                           | Class                      | What it is                                                                                              |
| --------- | --------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------- |
| `control` | `<span>` (Base UI `Switch.Root`)  | `dextinitySwitch__control` | The track, which has the `switch` role, receives focus and gets the props the component doesn't handle. |
| `thumb`   | `<span>` (Base UI `Switch.Thumb`) | `dextinitySwitch__thumb`   | The round handle, which moves to the end while the switch is on.                                        |
| `label`   | `<label>`                         | `dextinitySwitch__label`   | The text, `children`, which names the switch. Rendered only when there are `children`.                  |

## Design tokens

A theme styles the switch through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the switch's own: they're shared tokens, which other components can use too. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the switch                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-border-strong`                                                                                                                                           | Background of the track while the switch is off.                                                                                                     |
| `--dextinity-color-border-hover`                                                                                                                                            | Background of the track while the switch is off and the track or its label is hovered. A `readOnly` track keeps its color.                           |
| `--dextinity-color-primary`                                                                                                                                                 | Background of the track while the switch is on.                                                                                                      |
| `--dextinity-color-primary-hover`                                                                                                                                           | Background of the track while the switch is on and the track or its label is hovered. A `readOnly` track keeps its color.                            |
| `--dextinity-color-surface`                                                                                                                                                 | Color of the thumb.                                                                                                                                  |
| `--dextinity-control-toggle-size`                                                                                                                                           | Height of the track, which is twice as wide. The thumb sits 2px inside the track's edge, so it is 4px smaller.                                       |
| `--dextinity-radius-full`                                                                                                                                                   | Corner radius of the track and the thumb.                                                                                                            |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the label.                                                                                                                             |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the label.                                                                                                                            |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Text style of the label. The track is centered on the label's first line.                                                                            |
| `--dextinity-space-md`                                                                                                                                                      | Gap between the track and the label.                                                                                                                 |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline of the track focused with the keyboard.                                                                                                      |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of a disabled switch, the track and its label together, also when an enclosing Base UI `Fieldset` or `Field.Root` disables it.               |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the track's background color, and of the thumb as it slides to the other end.                                                          |
| `--dextinity-control-border-width`                                                                                                                                          | Width of the outlines that draw the track and the thumb in a forced colors mode, such as a Windows contrast theme, which replaces their backgrounds. |
