## Slots

`className` and `style` go to the field's outer element, the `dextinityTextField` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`, `required`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

A text field is a [`FormField`](?path=/docs/components-formfield--docs) around an input, so its root carries both root classes, `dextinityFormField dextinityTextField`, and the label, description and error have the form field's classes.

| Slot                | Element                             | Class                                   | What it is                                                                         |
| ------------------- | ----------------------------------- | --------------------------------------- | ---------------------------------------------------------------------------------- |
| `input`             | `<input>` (Base UI `Input`)         | `dextinityTextField__input`             | The input, which gets the props the component doesn't handle.                      |
| `label`             | `<label>` (Base UI `Field.Label`)   | `dextinityFormField__label`             | The label, which holds `label` and the required indicator.                         |
| `requiredIndicator` | `<span>`                            | `dextinityFormField__requiredIndicator` | The asterisk after the label of a `required` field. Assistive technology skips it. |
| `description`       | `<p>` (Base UI `Field.Description`) | `dextinityFormField__description`       | The `description`.                                                                 |
| `error`             | `<div>` (Base UI `Field.Error`)     | `dextinityFormField__error`             | The error message. Rendered only while there is an error to show.                  |

## Design tokens

A theme styles the text field's input through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the text field's own: they're shared tokens, which other components can use too. `TextField` renders a `FormField` for its label, description and error message, so the [FormField design tokens](?path=/docs/components-formfield--design-tokens) style those and the space between the parts. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the text field                                                                                                                                                                                       |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                 | Background of the input.                                                                                                                                                                                |
| `--dextinity-color-border-strong`                                                                                                                                           | Border color of the input.                                                                                                                                                                              |
| `--dextinity-color-border-hover`                                                                                                                                            | Border color of the hovered input. A focused, invalid or `readOnly` input keeps its border.                                                                                                             |
| `--dextinity-color-primary`                                                                                                                                                 | Border color of the focused input, also when it was focused by clicking. An invalid input keeps its danger border.                                                                                      |
| `--dextinity-color-danger`                                                                                                                                                  | Border color of an invalid input, also while focused or hovered. The input is invalid while the field shows an error: the `error` prop, or the browser's message for a failed check such as `required`. |
| `--dextinity-control-border-width`                                                                                                                                          | Border width of the input.                                                                                                                                                                              |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of the input.                                                                                                                                                                             |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of the input. The text field comes in this one size.                                                                                                                                     |
| `--dextinity-space-lg`                                                                                                                                                      | Horizontal padding inside the input.                                                                                                                                                                    |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the value.                                                                                                                                                                                |
| `--dextinity-color-foreground-muted`                                                                                                                                        | Text color of the `placeholder`.                                                                                                                                                                        |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the value and the placeholder.                                                                                                                                                           |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Size, line height, weight and letter spacing of the value and the placeholder.                                                                                                                          |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline of the focused input. Browsers show it on a text input also when it was focused by clicking, not only with the keyboard.                                                                        |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of the input of a `disabled` field.                                                                                                                                                             |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the input's border color as it is hovered, focused or marked invalid.                                                                                                                     |
