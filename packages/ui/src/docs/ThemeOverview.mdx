# Theme overview

The value of every [design token](?path=/docs/foundations-design-tokens--docs) in the theme picked in the toolbar: the colors in both color schemes, the text styles, the spacing, the shapes and the rest. Switch the theme in the toolbar to compare themes. The values come from the theme stylesheets in `packages/ui/src/themes/`, and the tokens and their descriptions from the design tokens page, so this page always shows the current state.
