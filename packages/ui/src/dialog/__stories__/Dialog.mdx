## Slots

`className` and `style` go to the popup, the `dextinityDialog` element with the `dialog` role (Base UI `Dialog.Popup`), and so do the props the component doesn't handle. `slotProps` adjusts the other parts; the description, the body, the actions and the close button are rendered only when the dialog has the content they hold. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`size`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs). The trigger keeps its own classes, and so does an icon button inside a `Tooltip` that is the trigger: the tooltip passes the dialog's props on to it. `DialogClose` renders no element of its own, so the button inside it keeps its classes too.

| Slot          | Element                              | Class                          | What it is                                                                                                                                                                                                                                  |
| ------------- | ------------------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backdrop`    | `<div>` (Base UI `Dialog.Backdrop`)  | `dextinityDialog__backdrop`    | The layer that dims the page behind the dialog. It only dims: clicks beside the dialog land on the viewport above it. It carries the theme of a `ThemeSwitch` around the trigger.                                                           |
| `viewport`    | `<div>` (Base UI `Dialog.Viewport`)  | `dextinityDialog__viewport`    | The element that covers the window above the backdrop and centers the popup in it. A click on it, beside the popup, closes the dialog, unless `disablePointerDismissal` is set. It carries the theme of a `ThemeSwitch` around the trigger. |
| `title`       | `<h2>` (Base UI `Dialog.Title`)      | `dextinityDialog__title`       | The `title`, which names the dialog. `{ render: <h3 /> }` changes the heading level.                                                                                                                                                        |
| `description` | `<p>` (Base UI `Dialog.Description`) | `dextinityDialog__description` | The `description`, which screen readers announce together with the title.                                                                                                                                                                   |
| `body`        | `<div>`                              | `dextinityDialog__body`        | The element around the `children`. While they don't fit and scroll, it has `data-scrollable` and can receive focus.                                                                                                                         |
| `actions`     | `<div>`                              | `dextinityDialog__actions`     | The element around the `actions`, at the bottom end of the dialog.                                                                                                                                                                          |
| `close`       | `<button>` (Base UI `Dialog.Close`)  | `dextinityDialog__close`       | The close button in the top corner, an `IconButton` with a cross, named by `closeLabel`. It carries the `dextinityButton dextinityIconButton` classes too.                                                                                  |

## Design tokens

A theme styles the dialog through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the dialog's own: they're shared tokens, which other components can use too. They style the backdrop, the popup and its parts. The close button is an `IconButton`, and the trigger and the actions are buttons of their own, which the [button's tokens](?path=/docs/components-button--docs) style. Inside a `ThemeSwitch`, the dialog takes the values of the theme switch's theme, like the trigger. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                                                                              | In the dialog                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--dextinity-color-backdrop`                                                                                                                                                                                                       | Color of the backdrop, which covers the page behind the dialog.                                                                                                                                              |
| `--dextinity-opacity-backdrop`                                                                                                                                                                                                     | Opacity of the backdrop, which keeps the page faintly visible.                                                                                                                                               |
| `--dextinity-z-index-dialog`                                                                                                                                                                                                       | Stacking order of the backdrop and the dialog, above the page. Popups and tooltips that open from the dialog stack above it.                                                                                 |
| `--dextinity-color-surface`                                                                                                                                                                                                        | Background of the popup.                                                                                                                                                                                     |
| `--dextinity-color-border`                                                                                                                                                                                                         | Border color of the popup, and of the lines above and below the content while it scrolls.                                                                                                                    |
| `--dextinity-radius-large`                                                                                                                                                                                                         | Corner radius of the popup.                                                                                                                                                                                  |
| `--dextinity-shadow-dialog`                                                                                                                                                                                                        | Shadow of the popup, which lifts it above the backdrop.                                                                                                                                                      |
| `--dextinity-color-foreground`                                                                                                                                                                                                     | Text color of the title and the content.                                                                                                                                                                     |
| `--dextinity-color-foreground-muted`                                                                                                                                                                                               | Text color of the description.                                                                                                                                                                               |
| `--dextinity-font-family-heading`, `--dextinity-typography-heading-4-font-size`, `--dextinity-typography-heading-4-line-height`, `--dextinity-typography-heading-4-font-weight`, `--dextinity-typography-heading-4-letter-spacing` | Text style of the title. The close button is centered on the title's first line.                                                                                                                             |
| `--dextinity-font-family-body`, `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing`                        | Text style of the description and the content. Fields and buttons in the content set their own.                                                                                                              |
| `--dextinity-space-xs`                                                                                                                                                                                                             | Space between the title and the description.                                                                                                                                                                 |
| `--dextinity-space-sm`                                                                                                                                                                                                             | Gap between the actions. The close button's icon moves by it towards the corner.                                                                                                                             |
| `--dextinity-space-lg`                                                                                                                                                                                                             | Space above the content, and between the content and the lines around it while it scrolls. Gap between the title and the close button.                                                                       |
| `--dextinity-space-xl`                                                                                                                                                                                                             | Padding of the popup, space between the popup and the window's edges, and space above the actions.                                                                                                           |
| `--dextinity-control-height-small`                                                                                                                                                                                                 | Height of the close button, a small `IconButton`, which centers it on the title's first line.                                                                                                                |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                                                                                    | Outline of the scrolling content focused with the keyboard, drawn inside its edges. The width and the offset also keep room around the content, so the outline of a focused field at its edge isn't cut off. |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                                                                                  | Transition of the popup, which fades and grows in, and of the backdrop, which fades in, as the dialog opens, and back as it closes.                                                                          |
