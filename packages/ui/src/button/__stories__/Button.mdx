## Slots

`className` and `style` go to the button itself, the `dextinityButton` element. `slotProps` adjusts the inner parts, which are rendered only when the button has the content they hold. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`variant`, `size`, `tone`, `disabled`) that returns them. `ButtonLink` has the same slots; its `<a>` element carries both `dextinityButton` and `dextinityButtonLink`. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

| Slot        | Element  | Class                        | What it holds    |
| ----------- | -------- | ---------------------------- | ---------------- |
| `startIcon` | `<span>` | `dextinityButton__startIcon` | The `startIcon`. |
| `endIcon`   | `<span>` | `dextinityButton__endIcon`   | The `endIcon`.   |

## Design tokens

A theme styles the button through these [design tokens](?path=/docs/foundations-design-tokens--docs). The `--dextinity-button-*` tokens are the button's own; the others are shared tokens, which other components can use too. `IconButton` renders a button, so these tokens style it as well, except the horizontal padding, which an icon button doesn't have. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                               | In the button                                                                                                                                                            |
| ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--dextinity-button-radius`                                                                                                         | Corner radius.                                                                                                                                                           |
| `--dextinity-button-font-weight`                                                                                                    | Font weight of the text.                                                                                                                                                 |
| `--dextinity-button-primary-background`                                                                                             | Background of a primary button: a color or a gradient.                                                                                                                   |
| `--dextinity-button-primary-background-hover`                                                                                       | Background of a hovered primary button.                                                                                                                                  |
| `--dextinity-button-primary-foreground`                                                                                             | Text and icons of a primary button.                                                                                                                                      |
| `--dextinity-button-primary-shadow`                                                                                                 | Shadow of a primary button. A disabled button has none.                                                                                                                  |
| `--dextinity-button-secondary-background`                                                                                           | Background of a secondary button.                                                                                                                                        |
| `--dextinity-button-secondary-background-hover`                                                                                     | Background of a hovered secondary button.                                                                                                                                |
| `--dextinity-button-secondary-foreground`                                                                                           | Text and icons of a secondary button.                                                                                                                                    |
| `--dextinity-button-secondary-foreground-hover`                                                                                     | Text and icons of a hovered secondary button.                                                                                                                            |
| `--dextinity-button-secondary-border`                                                                                               | Border color of a secondary button.                                                                                                                                      |
| `--dextinity-button-ghost-foreground`                                                                                               | Text and icons of a ghost button.                                                                                                                                        |
| `--dextinity-button-ghost-background-hover`                                                                                         | Background of a hovered ghost button. It has none until hovered.                                                                                                         |
| `--dextinity-color-danger`, `--dextinity-color-success`                                                                             | Fill of a primary button, and text and border of a secondary or ghost button, with `tone="danger"` or `tone="success"`. Mixed with foreground on hover of a primary one. |
| `--dextinity-color-danger-subtle`, `--dextinity-color-success-subtle`                                                               | Background of a hovered secondary or ghost button with `tone="danger"` or `tone="success"`.                                                                              |
| `--dextinity-color-background`                                                                                                      | Text and icons of a primary button with `tone="danger"` or `tone="success"`.                                                                                             |
| `--dextinity-color-foreground`                                                                                                      | Mixed into the fill of a hovered primary button with `tone="danger"` or `tone="success"`, which darkens it in a light color scheme.                                      |
| `--dextinity-control-height-small`, `--dextinity-control-height-medium`, `--dextinity-control-height-large`                         | Minimum height of each `size`. A label that wraps makes it taller.                                                                                                       |
| `--dextinity-control-padding-inline-small`, `--dextinity-control-padding-inline-medium`, `--dextinity-control-padding-inline-large` | Horizontal padding of each `size`.                                                                                                                                       |
| `--dextinity-control-font-size-small`, `--dextinity-control-font-size-medium`, `--dextinity-control-font-size-large`                | Text size of each `size`. Icons are 1.25 times as large.                                                                                                                 |
| `--dextinity-control-border-width`                                                                                                  | Border width. Only a secondary button shows its border.                                                                                                                  |
| `--dextinity-font-family-body`                                                                                                      | Font family of the text.                                                                                                                                                 |
| `--dextinity-space-xs`                                                                                                              | Vertical padding, which keeps a wrapped label off the edges.                                                                                                             |
| `--dextinity-space-sm`                                                                                                              | Gap between the icons and the text.                                                                                                                                      |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                     | Outline of the button focused with the keyboard.                                                                                                                         |
| `--dextinity-opacity-disabled`                                                                                                      | Opacity of a disabled button.                                                                                                                                            |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                   | Transition of the background color and the text color on hover, and of the shadow when the button becomes disabled. A gradient background changes without a transition.  |
