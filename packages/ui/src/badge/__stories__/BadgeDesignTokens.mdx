# Badge design tokens

A theme styles the badge through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the badge's own: they're shared tokens, which other components can use too.

[Theme overview](?path=/docs/foundations-theme-overview--docs) shows each token's value in every theme.

| Token                                                                                                                                                                                                                                         | In the badge                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `--dextinity-color-neutral-subtle`                                                                                                                                                                                                            | Background of a `tone="neutral"` badge, the default.                                   |
| `--dextinity-color-foreground`                                                                                                                                                                                                                | Text color of a `tone="neutral"` badge.                                                |
| `--dextinity-color-primary-subtle`                                                                                                                                                                                                            | Background of a `tone="primary"` badge.                                                |
| `--dextinity-color-primary`                                                                                                                                                                                                                   | Text color of a `tone="primary"` badge.                                                |
| `--dextinity-color-success-subtle`                                                                                                                                                                                                            | Background of a `tone="success"` badge.                                                |
| `--dextinity-color-success`                                                                                                                                                                                                                   | Text color of a `tone="success"` badge.                                                |
| `--dextinity-color-warning-subtle`                                                                                                                                                                                                            | Background of a `tone="warning"` badge.                                                |
| `--dextinity-color-warning`                                                                                                                                                                                                                   | Text color of a `tone="warning"` badge.                                                |
| `--dextinity-color-danger-subtle`                                                                                                                                                                                                             | Background of a `tone="danger"` badge.                                                 |
| `--dextinity-color-danger`                                                                                                                                                                                                                    | Text color of a `tone="danger"` badge.                                                 |
| `--dextinity-font-family-body`                                                                                                                                                                                                                | Font family of the text.                                                               |
| `--dextinity-typography-overline-font-size`, `--dextinity-typography-overline-line-height`, `--dextinity-typography-overline-font-weight`, `--dextinity-typography-overline-letter-spacing`, `--dextinity-typography-overline-text-transform` | Size, line height, weight and letter spacing of the text, and whether it is uppercase. |
| `--dextinity-space-xs`                                                                                                                                                                                                                        | Vertical padding, and the gap between an icon and the text.                            |
| `--dextinity-space-sm`                                                                                                                                                                                                                        | Horizontal padding.                                                                    |
| `--dextinity-radius-small`                                                                                                                                                                                                                    | Corner radius.                                                                         |
