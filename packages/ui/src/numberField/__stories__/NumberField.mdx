## Slots

`className` and `style` go to the field's outer element, the `dextinityNumberField` element. `slotProps` adjusts the inner parts. Each slot takes an element's props, merged with the slot's own, or a function of the owner state (`disabled`, `required`, `readonly`) that returns them. `render` replaces a slot's element. See [Customization](?path=/docs/foundations-customization--docs).

A number field is a [`FormField`](?path=/docs/components-formfield--docs) around Base UI's number field, so its root carries both root classes, `dextinityFormField dextinityNumberField`, and the label, description and error have the form field's classes. Between the root and the group, Base UI's `NumberField.Root` renders a `<div>` without a class, which isn't a slot. `ref` and the props the component doesn't handle go to the input.

| Slot                | Element                                      | Class                                   | What it is                                                                                                                      |
| ------------------- | -------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `group`             | `<div>` (Base UI `NumberField.Group`)        | `dextinityNumberField__group`           | The box with the border around the input and the step buttons. It has the `group` role.                                         |
| `input`             | `<input>` (Base UI `NumberField.Input`)      | `dextinityNumberField__input`           | The input, which shows the formatted value, receives focus and the props the component doesn't handle.                          |
| `decrement`         | `<button>` (Base UI `NumberField.Decrement`) | `dextinityNumberField__decrement`       | The button that decreases the value by `step`. Its `children`, the `minus` icon, can be replaced. Hidden in a `readOnly` field. |
| `increment`         | `<button>` (Base UI `NumberField.Increment`) | `dextinityNumberField__increment`       | The button that increases the value by `step`. Its `children`, the `plus` icon, can be replaced. Hidden in a `readOnly` field.  |
| `label`             | `<label>` (Base UI `Field.Label`)            | `dextinityFormField__label`             | The label, which holds `label` and the required indicator.                                                                      |
| `requiredIndicator` | `<span>`                                     | `dextinityFormField__requiredIndicator` | The asterisk after the label of a `required` field. Assistive technology skips it.                                              |
| `description`       | `<p>` (Base UI `Field.Description`)          | `dextinityFormField__description`       | The `description`.                                                                                                              |
| `error`             | `<div>` (Base UI `Field.Error`)              | `dextinityFormField__error`             | The error message. Rendered only while there is an error to show.                                                               |

## Design tokens

A theme styles the number field's input and its stepper buttons through these [design tokens](?path=/docs/foundations-design-tokens--docs). None of them is the number field's own: they're shared tokens, which other components can use too. The input looks like a `TextField`'s, so a form looks uniform. `NumberField` renders a `FormField` for its label, description and error message, so the [FormField design tokens](?path=/docs/components-formfield--docs#design-tokens) style those and the space between the parts. The buttons show the `minus` and `plus` icons of the [icon set](?path=/docs/foundations-icons--docs), which a theme can replace. The values are those of the theme picked in the toolbar; the [theme overview](?path=/docs/foundations-theme-overview--docs) compares the themes.

| Token                                                                                                                                                                       | In the number field                                                                                                                                                                                               |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-color-surface`                                                                                                                                                 | Background of the box around the input and the buttons.                                                                                                                                                           |
| `--dextinity-color-border-strong`                                                                                                                                           | Border color of the box.                                                                                                                                                                                          |
| `--dextinity-color-border-hover`                                                                                                                                            | Border color of the hovered box. A focused, invalid or `readOnly` field keeps its border.                                                                                                                         |
| `--dextinity-color-primary`                                                                                                                                                 | Border color of the box while the input has focus, also when it was focused by clicking. An invalid field keeps its danger border.                                                                                |
| `--dextinity-color-danger`                                                                                                                                                  | Border color of an invalid field, also while focused or hovered. The field is invalid while it shows an error: the `error` prop, or the browser's message for a failed check such as `required`.                  |
| `--dextinity-control-border-width`                                                                                                                                          | Border width of the box.                                                                                                                                                                                          |
| `--dextinity-radius-medium`                                                                                                                                                 | Corner radius of the box.                                                                                                                                                                                         |
| `--dextinity-control-height-medium`                                                                                                                                         | Minimum height of the box. The number field comes in this one size.                                                                                                                                               |
| `--dextinity-space-sm`                                                                                                                                                      | Space between the buttons and the box's edges: each button is a square as high as the box, minus this space above and below.                                                                                      |
| `--dextinity-space-lg`                                                                                                                                                      | Horizontal padding around the value, which lines it up with the value of a `TextField`.                                                                                                                           |
| `--dextinity-radius-small`                                                                                                                                                  | Corner radius of the buttons, visible while one is hovered.                                                                                                                                                       |
| `--dextinity-color-surface-hover`                                                                                                                                           | Background of a hovered button. A button that is disabled because the value reached `min` or `max` has none.                                                                                                      |
| `--dextinity-color-foreground`                                                                                                                                              | Text color of the value, and color of the minus and plus icons.                                                                                                                                                   |
| `--dextinity-color-foreground-muted`                                                                                                                                        | Text color of the `placeholder`.                                                                                                                                                                                  |
| `--dextinity-font-family-body`                                                                                                                                              | Font family of the value and the placeholder.                                                                                                                                                                     |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing` | Size, line height, weight and letter spacing of the value and the placeholder. Digits have equal widths, so values line up. The icons are 1.25 times the font size.                                               |
| `--dextinity-color-focus-ring`, `--dextinity-focus-ring-width`, `--dextinity-focus-ring-offset`                                                                             | Outline around the box while the input has focus. Browsers show it on the input also when it was focused by clicking. A button that receives focus, which Tab never gives it, shows the outline inside its edges. |
| `--dextinity-opacity-disabled`                                                                                                                                              | Opacity of the box of a `disabled` field, and of a button that is disabled because the value reached `min` or `max`.                                                                                              |
| `--dextinity-motion-duration-medium`, `--dextinity-motion-easing`                                                                                                           | Transition of the box's border color as it is hovered, focused or marked invalid, and of a button's background on hover.                                                                                          |
