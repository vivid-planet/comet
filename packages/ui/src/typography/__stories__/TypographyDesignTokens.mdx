# Typography design tokens

A theme styles the text through these [design tokens](?path=/docs/foundations-design-tokens--docs). All of them are shared with other components, so changing one changes those components too. Each `variant` takes its text style from its own tokens and one of the two font families, and the `tone` picks the text color.

[Theme overview](?path=/docs/foundations-theme-overview--docs) shows each token's value in every theme.

| Token                                                                                                                                                                                                                                         | In the text                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `--dextinity-font-family-heading`                                                                                                                                                                                                             | Font family of the `display`, `heading1`, `heading2`, `heading3` and `heading4` variants.                               |
| `--dextinity-font-family-body`                                                                                                                                                                                                                | Font family of the `bodyLarge`, `body`, `bodySmall`, `label` and `overline` variants.                                   |
| `--dextinity-color-foreground`                                                                                                                                                                                                                | Text color with `tone="default"`, the default.                                                                          |
| `--dextinity-color-foreground-muted`                                                                                                                                                                                                          | Text color with `tone="muted"`.                                                                                         |
| `--dextinity-typography-display-font-size`, `--dextinity-typography-display-line-height`, `--dextinity-typography-display-font-weight`, `--dextinity-typography-display-letter-spacing`                                                       | The `display` variant: font size, line height, font weight and letter spacing.                                          |
| `--dextinity-typography-heading-1-font-size`, `--dextinity-typography-heading-1-line-height`, `--dextinity-typography-heading-1-font-weight`, `--dextinity-typography-heading-1-letter-spacing`                                               | The `heading1` variant: font size, line height, font weight and letter spacing.                                         |
| `--dextinity-typography-heading-2-font-size`, `--dextinity-typography-heading-2-line-height`, `--dextinity-typography-heading-2-font-weight`, `--dextinity-typography-heading-2-letter-spacing`                                               | The `heading2` variant: font size, line height, font weight and letter spacing.                                         |
| `--dextinity-typography-heading-3-font-size`, `--dextinity-typography-heading-3-line-height`, `--dextinity-typography-heading-3-font-weight`, `--dextinity-typography-heading-3-letter-spacing`                                               | The `heading3` variant: font size, line height, font weight and letter spacing.                                         |
| `--dextinity-typography-heading-4-font-size`, `--dextinity-typography-heading-4-line-height`, `--dextinity-typography-heading-4-font-weight`, `--dextinity-typography-heading-4-letter-spacing`                                               | The `heading4` variant: font size, line height, font weight and letter spacing.                                         |
| `--dextinity-typography-body-large-font-size`, `--dextinity-typography-body-large-line-height`, `--dextinity-typography-body-large-font-weight`, `--dextinity-typography-body-large-letter-spacing`                                           | The `bodyLarge` variant: font size, line height, font weight and letter spacing.                                        |
| `--dextinity-typography-body-font-size`, `--dextinity-typography-body-line-height`, `--dextinity-typography-body-font-weight`, `--dextinity-typography-body-letter-spacing`                                                                   | The `body` variant, the default: font size, line height, font weight and letter spacing.                                |
| `--dextinity-typography-body-small-font-size`, `--dextinity-typography-body-small-line-height`, `--dextinity-typography-body-small-font-weight`, `--dextinity-typography-body-small-letter-spacing`                                           | The `bodySmall` variant: font size, line height, font weight and letter spacing.                                        |
| `--dextinity-typography-label-font-size`, `--dextinity-typography-label-line-height`, `--dextinity-typography-label-font-weight`, `--dextinity-typography-label-letter-spacing`                                                               | The `label` variant: font size, line height, font weight and letter spacing.                                            |
| `--dextinity-typography-overline-font-size`, `--dextinity-typography-overline-line-height`, `--dextinity-typography-overline-font-weight`, `--dextinity-typography-overline-letter-spacing`, `--dextinity-typography-overline-text-transform` | The `overline` variant: font size, line height, font weight, letter spacing, and whether its letters are all uppercase. |
