# IconButton design tokens

A theme styles the icon button through these [design tokens](?path=/docs/foundations-design-tokens--docs). `IconButton` renders a `Button`, so the [Button design tokens](?path=/docs/components-button--design-tokens) style it too. Its own stylesheet only adds the square width: it sets the width from the tokens below and removes the horizontal padding, so the button's horizontal padding tokens don't change it. The icon button has no tokens of its own: all of them are shared with other components, so changing one changes those components too.

[Theme overview](?path=/docs/foundations-theme-overview--docs) shows each token's value in every theme.

| Token                                                                                                       | In the icon button                                                                                           |
| ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `--dextinity-control-height-small`, `--dextinity-control-height-medium`, `--dextinity-control-height-large` | Width of each `size`. The button takes its minimum height from the same token, so the icon button is square. |
