Require `graphql-scalars` v2

Projects that depend on `graphql-scalars` themselves, for instance for the code generated by the API Generator, must update it to v2 as well. With two copies installed, the GraphQL schema can't be built because both define a scalar named `JSONObject`.

See the [migration guide](https://cms-docs.dextinity.com/docs/migration-guide/migration-from-v10-to-v11) for the required steps.
